#### 📹 CCTV Viewer (저부하 IP 카메라 뷰어 & AI 감지)
> **IE 웹 플러그인 없이 RTSP 기반 IP 카메라·NVR을 가볍게 모니터링하고 AI 감지까지 수행하는 데스크톱 뷰어**
- PyQt6 + PyAV(FFmpeg) 기반 저부하 멀티뷰 & 하드웨어 디코딩(`d3d11va` / `VAAPI` 자동 선택)
- YOLOX + ONNX Runtime AI 감지(사람·차량·동물) — **Windows GPU(DirectML) 우선 + CPU 자동 폴백**
- `go2rtc` + `Frigate` Docker Compose NVR 구성 지원 · MIT License(출처 표기 시 자유 이용)
